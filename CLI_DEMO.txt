=============================================================================
InsanusChat CLI - Complete Feature Set
=============================================================================

AUTHENTICATION COMMANDS:
------------------------
register              - Register a new user
login                 - Login with credentials
logout                - Logout current user
profile               - View your profile

CHAT MANAGEMENT:
----------------
chats                 - List all chats
chat new              - Create a new chat (NOW WORKS - message optional!)
chat select <id>      - Select a chat
chat delete <id>      - Delete a chat

MESSAGES:
---------
send <message>        - Send message to current chat
history               - View chat history

AGENTS:
-------
agents                - List all agents
agent new             - Create a new agent
agent delete <id>     - Delete an agent

API KEYS: ⭐ NEW
------------------
apikeys               - List all API keys
apikey add            - Add a new API key (provider, key, label)
apikey delete <id>    - Delete an API key

TOOLS/RESOURCES: ⭐ NEW
-----------------------
resources             - List all MCPs and snippets
mcp add               - Add a new MCP server (stdio/http/sse/websocket)
mcp delete <id>       - Delete an MCP server
snippet add           - Add a new code snippet (python/javascript)
snippet delete <id>   - Delete a code snippet

UTILITIES:
----------
clear                 - Clear screen
help                  - Show this help
quit/exit             - Exit the CLI
